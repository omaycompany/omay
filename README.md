# OMAY website

Bu klasör, `www.omay.com.tr` için ilk statik web sitesini içerir.

## Dosyalar

- `index.html`: Ana sayfa
- `yapay-zeka-hizmetleri.html`: AI Platform, LLM, GPU ve Yönetilen LLM hizmetleri
- `gpularimiz.html`: GPU seçenekleri ve kullanım detayları
- `blog.html`: Blog liste sayfası
- `blog/`: 10 adet güven veren blog yazısı
- `iletisim.html`: İletişim bilgileri ve teklif formu
- `404.html`: GitHub Pages özel hata sayfası
- `robots.txt`, `sitemap.xml`: Arama motoru keşfi için temel dosyalar
- `.nojekyll`: GitHub Pages'in statik dosyaları doğrudan yayınlaması için
- `styles.css`: Responsive tasarım
- `assets/gpu-datacenter-hero.png`: Hero görseli
- `assets/gpu-rtx-4090.png`, `assets/gpu-a100.png`, `assets/gpu-h100.png`: Paket görselleri
- `assets/omay-logo.svg`: Header logosu
- `assets/omay-mark.svg`: Favicon ve küçük marka işareti

## Yayına alma

Bu sürüm statik HTML/CSS olduğu için GitHub Pages üzerinde doğrudan yayınlanabilir.

GitHub Pages için önerilen yapı:

- Repository köküne bu klasördeki dosyaları koy.
- `Settings > Pages` bölümünde kaynak olarak `main` branch ve root dizinini seç.
- Custom domain alanına `www.omay.com.tr` yaz. Bu proje için `CNAME` dosyası hazırdır.
- DNS tarafında GitHub Pages'in istediği CNAME kaydını ekle.

## Yayından önce değiştirilecekler

- `info@omay.com.tr` adresinin gerçekten çalıştığını doğrula.
- WhatsApp numarası şimdilik eklenmedi.
- İlk gerçek tekliflerden sonra paket adları, minimum süreler ve teslim süreleri güncellenebilir.
